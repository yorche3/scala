**EN:** The project was created manually, without sbt or scaffolding tools. A single `.scala` file is enough: Scala is compiled to JVM bytecode before execution. For this standalone file, `scala-cli`, installed through Coursier, is used.

## 📄 Archivos de configuración clave / Key Configuration Files

No se requieren archivos de configuración de sbt para este ejercicio.

```scala
object HelloWorld {
  def main(args: Array[String]): Unit = {
    println("Hello, World! from Scala!")
  }
}
```

| Elemento | Propósito |
|----------|-----------|
| `object HelloWorld` | Declara un singleton object que contiene el punto de entrada del programa. |
| `def main(args: Array[String]): Unit` | Define la función `main` que la JVM utiliza como entrada. |
| `println(...)` | Escribe el mensaje en la salida estándar y añade un salto de línea. |
| `args: Array[String]` | Recibe los argumentos de línea de comandos. |
| `Unit` | Tipo de retorno equivalente a no devolver un valor significativo. |

> **ES:** Scala 3 también admite el formato de programa de nivel superior, pero este ejercicio conserva explícitamente `object HelloWorld` y `main` para mostrar el punto de entrada clásico compatible con la JVM.
> **EN:** Scala 3 also supports top-level program syntax, but this exercise explicitly keeps `object HelloWorld` and `main` to show the classic JVM-compatible entry point.

## 🚀 Compilación y ejecución / Build & Run

### Requisitos / Requirements

- **JDK** compatible con Scala/JVM.
- **Coursier** para instalar y gestionar Scala.
- **Scala 3.9.0** y **scala-cli 1.16.0** en el entorno utilizado para esta implementación.

La instalación realizada con Coursier añade sus ejecutables a `~/.local/share/coursier/bin` mediante los perfiles del shell:

```bash
# Cargar Coursier en la sesión actual
source ~/.bash_profile

# Verificar las herramientas
java -version
scala -version
scalac -version
scala-cli version
```

Si Coursier aún no está instalado:

```bash
curl -fL https://github.com/coursier/coursier/releases/latest/download/cs-x86_64-pc-linux.gz \
  | gzip -d > cs
chmod +x cs
./cs setup
source ~/.bash_profile
```

### Ejecutar con scala-cli / Run with scala-cli

```bash
cd scala/core/foundations/helloworld
scala-cli run helloworld.scala
```

### Compilar manualmente / Compile manually

```bash
cd scala/core/foundations/helloworld
scalac helloworld.scala
```

> **ES:** `scalac` genera clases JVM en el directorio actual. `scala-cli run` es el flujo recomendado para este archivo independiente porque compila y ejecuta el programa en un solo comando y gestiona el classpath automáticamente.
> **EN:** `scalac` generates JVM classes in the current directory. `scala-cli run` is the recommended flow for this standalone file because it compiles and runs the program in one command while managing the classpath automatically.

### Salida esperada / Expected output

```text
Hello, World! from Scala!
```
